# Homebrew tap for Heft

A native macOS Markdown editor for an Obsidian vault, with a command line built for coding agents. The app itself lives at https://github.com/josteng/Heft.

```bash
brew install --cask josteng/heft/heft
```

That installs `Heft.app` and a `heft` command. `brew upgrade --cask heft` follows new releases.

Requires macOS 26.
